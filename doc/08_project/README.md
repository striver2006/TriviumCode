# 08_项目管理与过程记录 (Project Management)

本目录直接存放所有项目排期路线图、迭代里程碑、敏捷记录与会议评审纪要（扁平结构，无子目录），通过文件名前缀区分文档类型。

---

## 文件命名规范

| 前缀 / 格式 | 文档类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `ROADMAP.md` | 版本路线图 | 项目整体愿景、关键交付里程碑与时间线。 | `ROADMAP.md` |
| `BACKLOG.md` | 需求/待办池 | 未排期需求、技术债务追踪与优化项。 | `BACKLOG.md` |
| `MEETING_<日期>_<主题>.md` | 会议/评审纪要 | 架构评审、迭代规划、复盘会议纪要与 Action Items。 | `MEETING_2026-09-10_pipeline_review.md` |
| `CHANGELOG.md` | 变更日志 | 业务侧版本发布说明与特性汇总。 | `CHANGELOG.md` |

---

## 记录规范
- 会议与评审纪要需清晰标注：时间、参会人（人类/智能体）、主要结论、待办事项（责任人、预计完成时间）。
