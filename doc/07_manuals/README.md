# 07_用户手册与操作指南 (Manuals & Guides)

本目录直接存放所有面向终端用户、开发者与运维人员的上手指南与操作手册（扁平结构，无子目录），通过文件名前缀区分文档类型。

---

## 文件命名规范

| 前缀 / 格式 | 文档类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `QUICKSTART.md` | 快速入门 | 5 分钟极速上手跑通核心流程。 | `QUICKSTART.md` |
| `MANUAL_<角色/模块>.md` | 操作手册 | 面向特定角色（开发者、架构师、管理员）的操作指南。 | `MANUAL_developer.md` |
| `FAQ.md` / `FAQ_<主题>.md` | 常见问答 | 常见问题汇总与快速排障自查清单。 | `FAQ_general.md` |
| `CHEATSHEET_<名称>.md` | 速查表 | 快捷命令清单、VS Code 快捷操作一览。 | `CHEATSHEET_cli_shortcuts.md` |

---

## 编写原则
- 步骤清晰、提供复制即用的命令与配置片段。
- 给出预期的输入示例与控制台输出效果对比。

---

## 当前已归档文件

- [稳定版使用手册](./稳定版使用手册.md)：当前日常操作入口，含四类任务、路线、裁决、人工审批和故障处理。

- [`QUICKSTART.md`](./QUICKSTART.md)：Driver-DualCritic 双审流水线快速上手。目标是**15 分钟内**装好并跑通一条真实任务——前置条件、安装、探针实测、项目启用、第一条任务、三道护栏、产出位置与排障。
- [`MANUAL_user.md`](./MANUAL_user.md)：**使用手册**（当前版本见其文档头，状态：草稿）。面向第一次接触本工具的使用者，不假定任何前置知识。心智模型、安装与启用（含两个「不会自动升级」的坑）、七条命令的完整契约、`.trivium/config.yaml` 全部字段逐条说明、怎么读审查结论与写裁决、日常场景、五道护栏（含一道非机械的）、按症状分类的排障，以及第十章如实列出的已知限制。
  与 QUICKSTART 的分工：QUICKSTART 是「照着敲 15 分钟跑通」，本手册是「理解每一步在干什么，并能应对没照着剧本走的情况」。
