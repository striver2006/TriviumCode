## 9. 风险与暂缓

- **措辞可能在别的焦点下失效**：本轮只验了一种焦点形态（明确点名要调用）。若之后再出现执行型调用，按 EV-191 的新触发条件转向缓解②（关通道）；
- **点名可能诱发好奇**：不点名时该工具本来就在每次请求的工具清单里；本轮样本只有 1，不量化；
- **委派给子代理**（代码双审 CODEX-01）：禁令说的「一被调用即判只读失守」只对主会话成立，子代理会话不在核验面（EV-189）。焦点仍要求调用时，委派是既满足焦点又不碰禁令的路径；本轮效果层 glm 没有派子代理（rollout 调用只有 Read / Glob），这一形态未被触及。已并进 EV-189 的触发条件，任务书不写检测边界；
- **「另有」的存在断言**（代码双审 CODEX-02）：前提是插件缓存随副本 HOME 带入该工具，渲染期不核验；工具消失时这句失实但没有失守后果；
- **名单外 MCP 工具不点名**：登 EV-192 待议；
- **安装副本**：本仓双审走的是安装副本，本主题改动只有重装后才对日常双审生效；提交后需先从已提交状态重建、再请用户重装。
