# 01_需求工程 (Requirements)

本目录直接存放所有需求阶段文档（扁平结构，无子目录），通过文件名前缀区分文档类型。

---

## 文件命名规范

| 前缀 / 格式 | 文档类型 | 说明 | 示例 |
| :--- | :--- | :--- | :--- |
| `PRD_<名称>.md` | 产品需求文档 | 描述业务痛点、用户画像、核心功能、优先级与交互流程。 | `PRD_multi_agent_workflow.md` |
| `SRS_<名称>.md` | 软件需求规格说明书 | 描述系统详细功能规格、非功能指标（性能/安全）、异常边界与约束。 | `SRS_file_relay_bus.md` |
| `STORY_<名称>.md` | 用户故事 / 任务卡 | 敏捷开发中的独立用户故事与验收标准拆解。 | `STORY_patch_parser.md` |
| `*_TEMPLATE.md` | 编写规范模板 | 提供标准编写格式骨架。 | [`PRD_TEMPLATE.md`](./PRD_TEMPLATE.md) |

---

## 需求状态管理
建议在文档内元信息区注明当前状态：
`[草稿(Draft) -> 评审中(In-Review) -> 已批准(Approved) -> 研发中(In-Dev) -> 已上线(Done)]`
