## 2. Driver 侧复核实测

全部在 `mktemp -d` 返回的**可写**临时目录内进行（审查侧只读，故三侧用的是报错文本法；
我这边能直接看建出什么文件，两种方法互证）。

### 2.1 blocker 那一格（判 CODEX-01 ≡ AGY-01 ≡ GLM-01）

| 命令（zsh 5.9） | rc | 建出文件 | 语义 |
| :--- | :--- | :--- | :--- |
| `echo A >&\| 2` | 0 | **`2`** | **文件**（非 fd 复制） |
| `echo B >&!2` | 0 | **`2`** | **文件** |
| `echo C >&\| -` | 0 | **`-`** | **文件**（非关闭 fd） |
| `echo D 2>&! 1` | 0 | **`1`** | **文件** |

**结论**：clobber 后缀**消去** fd 语义。`isFdOp` 必须去掉 `[|!]?`。

### 2.2 普通覆盖后缀（判 CODEX-02）

`echo P >| p1.txt`、`>! p2.txt`、`>>| p3.txt`、`>>! p4.txt` ⇒ **四种全部 rc=0 且建出文件**。

今天的行为（旧正则 `/^[0-9]*>>?/`）：紧贴形态写目标被错记成 `|p1.txt`；
分离形态目标丢失且 `p1.txt` 以假读取进读面。改动① 会顺带修正，但计划三处未登记。

### 2.3 fd 变量重定向（判 CODEX-03）

`echo T {fd}> fdvar.txt` ⇒ rc=0，**建出 `fdvar.txt`**。
新旧两版正则均以 `^` 锚定，`{` 打头永不匹配 ⇒ 文法外的静默写通道。

### 2.4 bash 分离形态（判 CODEX-04）

`/bin/bash -c 'echo X >& bashsep.txt'` ⇒ **rc=0 且建出文件** ⇒ 该形态在 bash 下可达。
「bash 下这些形态退非零」只对带数字前缀的 `2>&文件` 成立。

### 2.5 两处代码事实

- **AGY-02**：`base.ts:844-846` 确实用 `!consumed.has(i)` 过滤写动词操作数 ⇒ 漏 `consumed.add(i+1)` 会让被排除的数字篡改写目标。
- **GLM-03**：`base.ts:611` 的「像路径」判据 `!t.includes('/') && !/\.[A-Za-z0-9]+$/.test(t)` ⇒ 纯数字进不了读面，我 §3.3 举的例子走不通。
