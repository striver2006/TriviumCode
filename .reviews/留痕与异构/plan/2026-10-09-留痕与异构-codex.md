# 留痕与异构实施计划

日期：2026-10-09；Driver：codex；M11 第 12 步全量验收的前置任务之三。

## 目标与边界

执行用户批准的「Codex、Claude Code 双模式接入与异构判定修正」。前两个主题提供实际路由、探针指纹与逐组合认证；本主题实现诚实留痕和模型族三态比较。Agent 身份、归档命名、意见前缀及护栏沿注册表；供应商或模型都不改身份。同族、未知一律告警继续，不构成门禁，不自动换模型。提交、推送待用户确认，软件版本号由用户控制。

## 契约与迁移

1. 先将 v3 字段、来源和异构语义并入主设计，同步 PRD FR-17/AC-18 与协议。新写 `trivium.run.v3`，保留 v1/v2 原始 Schema 与冻结历史工件。读侧先根据 schema 用各自校验器验证原形状，再转统一内存形状；不得放宽旧 Schema 以强塞新字段，也不得将旧布尔值重新解释为新比较。
2. v3 路由证据记录请求模式/profile、实际入口、CLI 与包装器指纹；配置供应商与运行时回读供应商分别记录值/来源，请求和回读模型、effort 分开。没有运行证据的字段为 null，不以请求回填有效值。Claude 经 Qwen 启动仅能声明 Qwen，Claude provider/effort 无事件回读时 null。成功、失败、超时、取消均保留请求路线，未启动的实际入口字段不伪造。
3. `meta.ts`、`schemas.ts`、`archive.ts`、`gate.ts`、`hooks.ts`、`review.ts`、`run-protocol.ts`、worker 交接、`parse.ts`、`render.ts`、`report.ts` 的读写链路一并更新，明确 source_schema。verify 阶段继续自身 verify-run 契约，不误升级。Schema 只校形状，身份仍注册表校验，新增文件自动进入目录对账。
4. `--driver-model`、`--driver-provider` 为可选本轮会话声明。通过 resolve/preflight/review/worker 透传至运行元数据，来源固定为 declared。缺值退64，不从审核者配置或 Driver Agent vendor 推断主攻当前模型。声明与运行时回读清楚区分。
5. 集中维护保守模型族解析器（注册表的模型事实源或由注册表导出的函数）。已识别模型标识映射家族；通用别名 opus/sonnet/default、未知标识返回 unknown，不用 provider 名作族判据。支持版本后缀和provider命名空间，避免 gpt-oss 等开源族误等同 GPT 服务模型；供应商承载不同模型族必须正确分开。
6. 比较 Driver 声明模型与每个审核者有效回读模型，审核者之间两两比较，输出 same-family/different-family/unknown、参与方、判断来源与原因。Driver 信息缺失、别名未知、审核者未回读均 unknown，禁止 requested fallback。provider 仅作上下文，不构成异构证据。
7. 所有展示面和意见头部一致输出三态及理由；同族与未知都明确告警但继续。旧 v1/v2 heterogeneous 布尔显示为「旧版名义族判定」，保留原文，不捏造本轮 driver declaration。override_reason 文案不再依据 Driver 厂商名义族，历史原因不回改。收口 EV-107、EV-234 与相关 EV-230 文案。

## 验证与交付

测试不同 Agent 同族、同一 provider 不同族、别名未知、Driver 缺失、审核者有效模型缺失、Claude声明与回读分离、三侧所有两两比较，以及 native/profile 失败留痕。真实桩进程证明 driver 声明与请求 route 跨 worker 传递，断言 stub CLI 指纹。保留 v1/v2 严格读取与历史展示夹具，v3 走完整审查→裁决→gate→审批测试→report→Hook 提交锚链；审批仅在测试夹具，用户生产审批不代执行。

关键接线加变异验证，Antigravity/ZCode 回归。入口参数改 skills-src 后 npm run render，同步主设计/ADR/PRD/PROTOCOL/使用和运维文档/验收剧本/AGENTS/开发指南及测试报告索引；冻结历史材料不回改。正式代码审查逐条裁决、修复与 verify。最终串行两次 npm run check、桩自检14/14、重装核 hash、七条当前路线验收通过并恢复三审后，方可宣布前置任务完成，随后执行 M11 第12步。真实验收48次上限与四批12次约束沿第二主题，全局共用计数，官方Claude标待订阅恢复。
