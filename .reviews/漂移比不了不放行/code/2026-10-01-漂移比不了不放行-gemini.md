## 认为正确的部分

- 实现严格遵循计划 r2 与用户决策：跑后漂移复算改用失败即抛的严格助手 diffTreesNameStatus，比不了判为 unknown 并按 review.on_drift_related（缺省 fail）处置，彻底堵住了此前 diffTrees 失败返回空列表被误判为「无漂移」的漏洞。
- 严格助手引入 -z 参数，正确保留了路径中的特殊字符（制表符、引号等），修复了此前旧调用中特殊字符路径因带 C 风格引号而无法匹配 scratch 白名单与相关路径的潜在漂移判定偏差。
- 在执行任何 git 命令前对两棵 tree 哈希值施加 OBJECT_NAME_RE 形状检查，并在报错中拒绝回显非法值，有效防御了以减号开头的值被当作 git 命令选项（如 --output）的注入风险。
- classifyCompareFailure 异常分类设计严谨：超时优先返回 timeout 且不再探测对象库；送审快照与跑后复算快照两棵 tree 对称校验 treeExists，分清 object_gone 与 git_error，并正确截断首行报错至 300 字符。
