## 3. 方案（按 P-1～P-5 取建议项写；拍板不同则按 §5 的分支改）

### 3.1 config 契约（任务一）

**schema `config.v2.json`**（原地扩，`$schema` 标识不变）：

- `$defs` 新增：
  - `tierName`：`enum: [low, medium, high]`；
  - `effortValue`：`type: string, minLength: 1`——**不写枚举**（11.5 禁令 ①：原生枚举随模型而异，由预检对探针结论校验）；
  - `tierEntry`：`{model: string(minLength 1), effort?: effortValue}`，`additionalProperties: false`，`required: [model]`；
  - `tierEntryOpenai`：在 `tierEntry` 基础上加 `profile?: string(minLength 1)`；
  - `tierEntryModelOnly`：`{model}`（zcode 支用，见下）；
  - `stageModel`：`oneOf` 三形态——`string(minLength 1)`（裸 slug）｜ `{tier: tierName}`（`required: [tier]`，`additionalProperties: false`）｜ `{model, effort}`（两键都必填，`additionalProperties: false`）。
- 四个 agent 分支各加可选 `tiers`（`properties: {low, medium, high}`，`additionalProperties: false`，`minProperties: 1`）与可选 `default_tier: tierName`：
  - antigravity / anthropic 支：值为 `tierEntry`；
