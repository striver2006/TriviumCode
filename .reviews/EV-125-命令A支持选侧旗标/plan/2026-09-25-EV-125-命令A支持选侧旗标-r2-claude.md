## 1. 现状核实

### 1.1 为什么要做

M10b 第 2 步取了 §8 第 1 条的选项 (a)：缺省集合减去当轮 Driver（`critics.ts` :288）。这让非 claude Driver 的命令 A 能跑通，但留下两个缺口：

### 1.3 由 C9～C11′ 得出的判断

放开 `--critics` 之后，命令 A 的 S0 预检与实际入选**会不一致**：用户加进来的那一家，三个阶段的 slug 与探活都没查过。
B / C / D 也有同一缺口（C11），但代价不同：B / C / D 漏查时下一步 `--start` 就失败、零工件；**命令 A 漏查的是 code 阶段的 slug**——`--start` 只查当阶段，S2 过得去，要到 S6（编码已做完）才发现。这正是 `--stage all` 存在的理由（C9）。所以命令 A 这一格要在本题补上（D2），B / C / D 那一格只登记。
