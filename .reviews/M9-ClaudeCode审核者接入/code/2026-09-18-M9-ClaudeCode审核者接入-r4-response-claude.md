## 2. 修法

> 闸门期不改业务文件。以下是经审批后要落的改动。

### 2.1 契约扫描：剥插值 + 按文件下限 + 单源 + 具名边界（AGY-01 ≡ CODEX-01，含 GLM-03/04 ≡ CODEX-02、CODEX-07）

  不再让「我写对正则」成为前提。
- **防空转腿改按文件下限**：从全局 `scanned > 0` 改成**每个探针文件各有下限**
  （现况 claude ≥ 3、agy ≥ 1、zcode ≥ 1、codex ≥ 3），与源序断言的 `writes.length >= 4` 同一手法。
- **`SHAPES` 单源**：抽成模块级常量 / 一个 `scanPathDenyProductions(src)` 纯函数，
  正向用例与反面夹具**共用同一份**（GLM-03 ≡ CODEX-02：现在夹具守的是它自己那份副本）。
- **反面夹具补一条含 `${}` 插值的真实形状**，期望**必须红**——现在四条样本全是无插值的合成串。
- **具名登记不覆盖形态**（GLM-04，照 `registry-parity` 先例）：嵌套花括号正文、中间变量构造、
  `supported` 子串误命中，各注明由谁兜底（`tsc` 必填 / 无兜底需人工）。
- **`omitVerbose` 实拨点唯一性上机器判据**（CODEX-07）：断言 `src/` 里该实拨形态出现次数 == 1

**并把报告 §10.2 与台账 v1.3.22 那句「覆盖三种写形」按实跑结果改准**——

### 2.2 EV-42 / EV-43：让安全默认有机读落点，让闭集真的闭（CODEX-03 + CODEX-04 ≡ GLM-01 + AGY-03）

  这样「未结案不得记 true」是**结构上不可能写错**，而不是等人读 BACKLOG。
  §16.1 与 §3.7 该行随之改准。
- **EV-42 补否定结案路径**（AGY-03）：实测确定不支持逐文件规则时，
  以**否定结论结案**、`file_shape_verified` 记 `false`、`peer_deny_applied` 永久 false 并记入限制清单。
- **EV-43 的闭集以 §3.7 表行（或 `ClaudeProbe` 键集）为论域逐格标注，无遗漏**，

  否则清单会随新增字段继续脱漏。
  **同一次调用产出的多格必须同类**：`readonly_breach` 与 `denied_tool_in_trace` 同源（CODEX-04）；
  `headless_read_ok` 与 `readonly_breach` 按 EV-43 自己的判据**必须入形态相关**。
