- 失守判定只做文案选择、退出码与阻断计数在读留痕之前定死，读取失败一律回落原文案——降级方向安全；readRunMeta 对不存在/坏 JSON/不合契约的形状一律返回 null 且不抛（readFile/parse 全捕获、validateRunMeta 返回字符串数组），不存在新代码抛错把 Hook 打成 exit 1 静默放行的路径。
- migrateRunMetaV1 与 run.v1.json 都保证 snapshot.drift 必填（changed/files/policy），driftText 对「changed 真而 files 空」的比不了形态走 describeDriftUnknown 共用排版并容 unknown_reason 缺席，形状面上无 undefined 解引用风险。
- 作废命令的 driver 取该轮 run.json 的 driver 经 entryCommandOf 派生，未采信 state.json 的 gate.driver，与 EV-68 的「Hook 权威来源是 run.json.driver」纪律一致；U16 用 codex 的 $ 写法与缺省不同做了鉴别力前置断言。
- 未知/更潮 driver 的 run.json 会被 checkAgentIdentities 两段式身份校验判读不出、回落原文案——新旧构建版本偏斜下的降级路径正确；acceptance.mjs 把新旧两份构建的 package.json 依赖区与 package-lock.json 字节一致性做成前置且中途失败也在 finally 里清理 mkdtemp，跨进程对照的绑定（各构建用自己的 fixture 助手与 bundle）干净。
