**问题**：§4.2 认定 bin 与 effort 同构「零消费方」并倾向剔除不符合源码事实。codex 与 gemini 侧均真实消费配置中的 bin 作为自定义路径覆盖，且 claude 探针实现已有对 configured 参数的消费链路。丢弃 bin 会破坏多 Agent 配置的对称性，并剥夺用户指定非标准 claude 二进制路径的能力。

**建议**：在 ClaudeAgentConfig 与 config.v2.json 中保留 bin: string | null，默认置 null。在 doctor.ts 与 adapters/claude.ts 中补齐对接逻辑（读取 cfg.agents.claude.bin ?? probe.entrypoint），彻底闭合消费链。
