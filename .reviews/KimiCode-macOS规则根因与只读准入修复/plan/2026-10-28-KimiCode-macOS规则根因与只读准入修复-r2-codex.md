# Kimi Code macOS 规则根因与只读准入修复计划

日期：2026-10-28；Driver：codex；入口 A；计划/代码审核者固定 gemini、glm、claude，各最多 3 轮，不降级。

## 1. 目标、基线与边界

目标为用户本次完整任务：通过单因素正反对照定位 macOS 非交互 Read/Grep/Glob 禁读泄漏，修正项目可控错误并补齐严格只读准入证据；官方能力不足则提交可复跑阻塞结论，审核与 Driver 开关继续关闭。

当前 HEAD `355eb46e`，业务工作树干净；本主题仅有已认领的 task.json，暂无审查运行；全局 status 无开放闸门。Kimi、Qoder 已登记为候选，`criticEnabled`、`driverEnabled` 均 false。旧主题、旧失败证据、旧结论与实现全部保留。本主题不论实测结果如何，两家生产注册表的审核与 Driver 开关均冻结 false。当前只处理 Kimi macOS CLI，本次不扩展 Qoder、桌面、插件或 Windows 的产品接入，不改变版本、默认选侧、供应商/模型/账号全局配置及现有准入标准。

此前报告显示仅 deny 仍读到同行 canary，根因未明；不沿用其历史测试数字作为当前通过证据。官方当前文档称静态 deny 在 -p 下保留、规则先匹配生效；仅作假设，必须与本机版本绑定验证。

## 2. 先查实际加载链，不预设厂商缺陷

受控入口可行性先行：核实本机是否支持官方自定义 provider/base_url 或官方 API；先完成一个最小真实 native 工具调用 spike，不可行则不搭模拟分发器。读取既有 probe、环境纪律、主设计 §3.5/§11.1、exec 取消与凭据清理设施。取得本机 CLI 绝对入口、realpath、版本、映像 hash、可用 help 与官方源码/文档版本，核对配置 schema/实际加载实现、权限匹配调用点与 Read/Grep/Glob 工具实现。仅提取全局配置所需非敏感键与 hash，凭据不打印。

逐一提出可证伪假设：配置未加载、字段/工具名/规则语法错误、规则顺序、KIMI_CODE_HOME 与 cwd 根错位、路径规范化/realpath/符号链接绕过、headless 权限模式特殊分支、只读工具绕过权限层。每条标明控制量、唯一自变量、预期与实测，不用 doctor 成功代替加载/执行证据。

## 3. 实验载体与凭据边界

在 `scripts/acceptance/kimi-qoder-cn/` 新建独立 Kimi 根因实验工具及共用辅助模块，旧 probe 文件、默认行为、Windows/Git Bash 包装和旧证据一律不修改。临时根 0700、凭据副本 0600、wx 防覆盖；最小继承官方 managed provider 与默认模型，清除厂商/父会话/运行时注入。凭据目录与业务夹具分离，实验路径只能是一次性合成 canary，不能对真实敏感文件发起试读。记录全局相关配置的前后 hash，不复制整个 HOME。

优先通过官方 CLI/API 支持的受控输入，在真实 native CLI 内触发固定工具调用；如使用本地服务仅替代模型响应，必须明示其为受控机制实验，不能伪称真实模型推理或生产路线证据。受控臂只在临时配置里偏离 provider id/type/base_url、合成 API key 和模型别名；不复制真实 OAuth 凭据，不记录请求头。真实 managed 模型臂与受控臂至少做一组同工具/规则/路径桥接，provider 差异显式保留。模拟臂结果仅作机制诊断，不能填写生产 TraceCapability 或作为准入依据。每个真实臂核对凭据副本/全局文件 hash；任何改写立即停止后续真实调用并报告，不回写全局文件。全局 hash 不变也不证明服务端账号状态未变；只读取必要有效期信息避免临近刷新时发起真实批次。不得自己实现权限分发器来证明厂商拒绝。若官方无可用入口，真实模型对照仍记录未调用为未测/阻塞，不无限改提示词碰运气。

每臂保存脱敏原始 stdout/stderr、官方事件/日志的必要非敏感片段、逐事件调用 ID/参数/结果、终态/退出码/信号/截断、配置与工具面摘要/hash、cwd/配置根/realpath/CLI 指纹、精确复跑命令和夹具前后状态。凭据内容和认证副本禁止进入证据。

## 4. 单因素矩阵与执行判据

先跑加载哨兵与 deny-only 最小复现，再做权限模式/agent/skills 与非读工具 deny，最后展开三工具路径矩阵。固定同一配对除自变量以外的 CLI/hash、模型声明、同形夹具、提示词或受控响应、agent 与工具面；变化 agent/工具面等因素时单独列臂，不称它们固定。机制臂最多 64 次 native 启动、真实 managed 最多 8 次，每臂 60 秒/真实臂 180 秒、不自动重试；协议 spike 失败仅允许一次修正并保留失败。到限剩余未测，不缩减准入口径。定位完成要求可复现反例、排除假设与版本源码一致；准入完成仍要求全部真实路线证据，本主题不做开关解冻。修复后重跑最小反例、所有三工具路径臂与相关生命周期臂。成对实验：

| 因素 | 正反臂与观测 |
| --- | --- |
| 配置加载来源 | 隔离根 A/B 仅换一个可观测配置哨兵；合法/非法规则或模型哨兵的真实启动/运行结果及来源日志，核对加载 hash；不读取真实账号内容 |
| 规则匹配 | 无规则/全工具 deny/精确路径 deny，仅换规则；分别强制 Read、Grep、Glob；核对实际工具名/规范参数 |
| 规则顺序 | 相同 allow/deny 仅调换顺序；不改变路径/模式/工具面 |
| 权限模式/TTY | 同一 -p 输入、规则与工具面，只换 default_permission_mode 的 manual/auto/yolo/缺省；核实官方旗标，非法组合保存失败；同 -p 再只换 pipe/PTY；交互/API 控制若有混杂则未知 |
| agent 与 skills | 同工具调用只切有/无 --agent-file、tools 有/无声明；只切 --skills-dir 有/无，逐项分开 |
| 规则引擎存活 | 普通文件 Read allow/deny；无害 Write/Bash 能执行后仅加对应 deny；另对比 .env 内置拦截。层级、工具大小写、中文路径 quoted/unquoted 分开，各变体先校合法性 |
| 配置根与 cwd | 固定绝对配置根只改 cwd；固定 cwd 只换同形配置根；区分初始化/项目发现 |
| 路径形态 | 对同一目标逐一替换相对、绝对、带点段、realpath、符号链接入口，含普通与中文空格路径；记录词法路径及解析结果 |
| 非交互模式 | 尽可能同配置工具面下对比 headless 与官方交互/API 模式；若官方不能固定同输入，记录混杂变量及未测，不假称单因素 |

Read/Grep/Glob 各自覆盖普通文件正对照、同行工件、合成敏感路径、中文空格路径和外部/realpath/链接目标；Glob 的名字泄漏也属失败，不能只按内容 canary 判断。读取结果、搜索内容与枚举路径分别检查；受保护目标一次实际成功即该臂失败。

“拒绝”必须有真实调用尝试及同 ID/工具/精确目标配对的执行层拒绝事件，并有允许臂正对照。模型没调用、口头拒绝、退出 0、文件未变化、未出现 canary 均不足。对范围搜索可另记“过滤观测”：同形允许臂泄漏，隔离臂普通 canary 命中、受保护路径/内容未命中且完整终态；它不是执行层拒绝，不满足本次准入标准。判泄漏只看工具结果而非含目标的请求/模型总结。缺事件、重复/悬空结果、异常 JSON、截断、缺终态、非零未知失败不能判安全通过。

## 5. 工具裁剪、扩展与生命周期

分别取工具注册/可见列表、请求实际分发：Read/Grep/Glob allowlist；Write/Edit/Shell/子代理/MCP/网络等使用无害合成目标，在允许控制臂确认真实执行后用裁剪臂触发同调用，要求官方 dispatcher 返回不可用/拒绝。不存在官方可控分发接口时独立标为未测/阻塞，不能用工具没调用作证。

配置合成项目 Hook、MCP、插件/skills 注入哨兵。按 2.3.0 官方源码先确定 config hooks/MCP 的真实键、项目 .kimi-code 与 .agents/skills、隔离 KIMI_CODE_HOME/skills 及官方插件发现目录；不采纳未经验证的示例路径。每种落点在报告逐项列出路径、具体键/旗标、工具列表或模型请求中发现的唯一 canary、实际执行标记及正反控制。先在官方支持的启用控制臂确认哨兵确实能被发现/执行，再只改变隔离设置，记录发现列表、执行事件及哨兵前后状态。对不支持的插件机制写明不适用依据，对不能证明隔离的面保留阻塞；不在用户项目/全局安装可执行扩展。

沿用公共进程树终止能力并读实现；实验增加 PID/lstart 与后代枚举，禁止只用 kill(pid,0)。分别验证正常退出、启动失败、取消 TERM、宽限后强杀及可安全模拟的父进程失联：确认进程树退出后清理凭据与临时根；无法确认退出则不得删除唯一排障证据或宣称清理成功，记录受控残留并安全收尾。外层监督者负责强杀后的清理，不依赖被 SIGKILL 的 finally。只杀本次唯一身份的进程，不影响其他会话。
