## 2. 修法

### 2.1 拼接规则

```ts
const lines = help.split(/\r?\n/);
const at = lines.findIndex((l) => /(^|\s)--effort(\s|=|$)/.test(l));
if (at < 0) return [];
let text = lines[at]!;
for (let i = at + 1; i < lines.length; i++) {
  const l = lines[i]!;
  if (!/^\s/.test(l)) break;                 // 不以空白开头：段标题、顶格文本
  const t = l.trim();
  if (t === '' || t.startsWith('-')) break;  // 空行（含纯空白行）或下一个选项行
  text += ' ' + t;
}
// 以下与现行逐字相同，只把 line 换成 text
```

判据逐条落到用户给定的定义上：

| 行的形态 | 处置 | 依据 |
| :--- | :--- | :--- |
| 以空白开头、去空白后非空且不以 `-` 起头 | 拼入，继续看下一行 | 续行定义 |
| 去空白后以 `-` 起头（下一个长选项、`-p, --print` 一类短旗标） | 停 | 「下一个选项行」 |
| 空行或纯空白行 | 停 | 「空行即止」；纯空白行按空行算——它去空白后为空，不是续行 |
| 不以空白开头（`Commands:`、顶格正文） | 停 | 不满足「以空白开头」 |
| 文本结束 | 停 | — |

- **只向后、只连续**：拼接从锚点下一行起，遇第一个非续行即止，不跳过、不回看锚点之前的行；
- **锚点行不变**：仍是「第一个含 `--effort` 词的行」，正则不改（`--effort-budget` 之类不算的那一格照旧成立）；
- **解析规则不变**：括号、形状校验、`[]` / `null` 三态逐字沿用；单个空格连接不影响逐项 `trim()`，跨行的列表（`(low, medium,` / `high)`）也能取全；
- **只换局部变量名 `line` ⇒ `text`**，return 路径与类型不变。

### 2.2 文档块改准

- 删去「本机 2.1.291 实测原文（M11 第 1 步 F6）」那句单行转述，改为：本机 2.1.291 的取值列表折在锚点下一行的缩进续行上（夹具 `test/fixtures/claude-help-2.1.291.txt` 第 84～85 行），并写明续行判据与终止条件；
- 「格式一漂移就落 `null`」那段保留，补一句：续行只拼紧随其后、连续的缩进非选项行，遇选项行、空行或顶格行即止，**不会越过下一个选项去拿它的括号**——越不过去时结果是「锚点 + 本选项续行里没有括号 ⇒ `null`」。

### 2.3 不改的面

`probeClaudeEffortLevels`（拼 `stdout + '\n' + stderr` 后整体送解析）不动——stderr 在本机为空（codex 计划审实测：两流均为管道时 stderr 0 行、stdout 311 行）；即便有内容，它在 stdout 之后，只可能出现在锚点之后**更远**的位置，中间隔着 stdout 自身的段落与空行。`types.ts` 的 `effort_levels` 字段注释（`:822` 写「解析 `--effort` 行第一对圆括号里的列表」）只改一处措辞为「解析 `--effort` 行及其续行里第一对圆括号」，否则注释又成了失实断言；字段类型与三态语义不动。

## 5. 残余风险（不处理）

1. **锚点行仍是「第一个含 `--effort` 词的行」**：若厂商在别的选项的续行里用散文提到 `--effort`（如「overrides --effort」）且它排在 `--effort` 选项之前，锚点会落到那行，拼的是别人的续行。本机原文只有一处命中，用户给定「解析规则不变」，不收紧锚点。收紧（例如要求锚点去空白后以 `-` 起头）的代价：若某版只在散文里提到它，会从「错枚举 / null」变成 `[]`（「无此概念」，配了即退 64）。
2. **第一对括号若是单个合形状的词**（如 `(experimental)` 出现在列表之前）会落一项错枚举。这在拼接前就存在于单行形态，拼接把窗口扩到了续行。不加「至少两项」之类的新规则——那是改解析规则，超出用户给定。
3. **续行判据不看缩进深度**：一行以空白开头、非 `-` 起头即算续行，不核它是否与描述列对齐。Options 段内每个条目都以选项行起头、段间有空行，不存在「缩进的非选项行属于别的段落而中间没有空行或选项行」的形态，故不加。
4. **stdout 与 stderr 的拼接边角**（glm 计划审盲区补记）：若 stdout 恰以锚点或其续行收尾、stderr 首行又呈续行形态，会被拼入。现实形态下锚点居中、其后必有选项行挡住，不处理。
