## 1. 本轮的形状：**我改了语义，但只改了一半落点**

三对独立收敛里有两对指向同一个动作缺陷：

| 我做的语义变更 | 改了的落点 | **没改的落点** |
| :--- | :--- | :--- |
| EV-01 从「独立演进项」升为「M8 前置条件」 | BACKLOG EV-01、主设计 3.6 | **§16.1 M8 行、§16.1 表末行、§24.1 台账行** |
| J3 从「优先 agent 定义」倾向改为「优先 skills」 | 报告 §4.2/§8、§24.1 台账行 | **§18.1 待拍板 #16**（规范落点，仍写旧默认） |

**两处的后果形状一样**：同一份「唯一实现依据」对同一议题存下两个**相反**的答案，
而过期的那一边恰好是**别人会去查的那一边**——M8 规划者读 §16.1，
查决策的人读 §18.1，两张表都还在说旧话。

**这正是我记在项目记忆里的那条**：「改语义前先列清所有断言该语义的落点」。
r5 之前它在这个项目里已经犯过三次（GLM-02 在意见里点了 v1.3.5 那次），**这是第四次**。
而且讽刺的是：我在上一轮裁决件里刚写完「同一事实两个落点且会分叉」的教训，
这一轮就在**两个新议题上各犯一次**。

**教训不是「下次记得」**——那正是纪律 12 反对的形态。
真正的出口是让它变成会红的机制，但本轮不具备：`§16.1` / `§18.1` / `§24.1`
三张表的一致性是**语义一致性**，不是结构一致性，grep 级契约测试判不了。
所以我把它如实登记为 **EV-14**（文档三表一致性的机器判据），不假装本轮解决了。

## 4. 一条要带走的

两侧都没说这句，但它是本轮最该记的：

**我把「写下限定」当成了「守住强度」。** 报告 §4.3 那句「这一节是静态证据」
写得很清楚，§8 还专门写了「现在就改成默认值等于把静态证据当结论」——
然后我在主设计 §16.1 与 §21 里把同一件事转述成了断言。

这与本主题 r1 的 GLM-01 同形：那次是「我在 §10 标了『不得在测量前引用』，
然后在 §3.1 引用为结论」。当时我记的教训是「**免责声明写在别处等于没写**」。
**这一轮它换了个方向复发**：限定写在原处了，但**转述时丢了**。

所以教训要扩一句：**限定必须跟着结论一起搬家**。原处写了不算数，
落到每一个转述处才算数——而转述处恰恰是别人真正会读的地方。
