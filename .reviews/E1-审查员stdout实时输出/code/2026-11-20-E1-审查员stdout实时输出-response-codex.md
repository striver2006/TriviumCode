| GLM-01 | 接受 | 首次打开失败时可重试独占创建；原路径已被其他尝试占用时不得冒认。 | 写入器 EOF 恢复及 runner 的 raw_stdout_path 事实校正，加占用与瞬时失败用例。 |
| GLM-02 | 接受 | 手动安装态矩阵无法替代每次构建都执行的写侧状态机回归。 | 核心 check 内用真实子进程驱动短写、慢写、失败、超时、封口与截断。 |
| GLM-03 | 接受 | 慢写完成回调可能晚于换 inode。 | 以文件句柄所有权限制 confirmed 更新，故障用例核对迟到回调后终态字节。 |
| GLM-04 | 接受 | 核心规则调整需要同步流式边界样本。 | secrets 与 safeBoundary 双向注明规则契约并扩展 PEM 连续发布测试。 |
| AGY-01 | 接受 | 内容文件事件与巡检共享定时器会让安静侧迟迟得不到状态。 | StdoutTail 记录全侧巡检期限，事件不得推迟期限。 |
| AGY-02 | 接受 | 完整 PEM 和正文中讨论开始标记均可能无限延后无关输出。 | 复用 secrets 的 PEM 正则区分未决尾段、已闭合及普通提及，保留跨块整段脱敏等价测试。 |
| AGY-03 | 接受 | 已核实的事后脱敏重写需要可读的最终身份与异常标记。 | runner 将当前文件额外清扫事实送 seal，重验常规文件并发布新大小与身份，保留一致性告警。 |
| AGY-04 | 接受 | 取消过程等待内核写的时间必须有界。 | 抽取共同的有限等待，取消先标中断，挂起写返回后关闭旧句柄。 |
| AGY-05 | 接受 | 元数据写路径已经移出适配器。 | 将写端文件名、受限记录名豁免和标准日志名纳入契约对账。 |
| AGY-06 | 接受 | 超时、作废、真实跨进程写读和最终安装包空闲对照均应有可复跑记录。 | 自动检查消费真实核心文件，扩展桩夹具与生命周期脚本，归档最终构建的计量。 |
| AGY-07 | 接受 | 运行已清理或字节数失配时不应留下无效操作。 | 完整文件入口处理目录消失；发送可打开状态前核对实际长度。 |
| AGY-08 | 接受 | 重开时已清理的历史运行应从索引移除。 | 恢复 recentRuns 前检查 status.json，回收无效索引。 |
| AGY-09 | 接受 | 重试后上一视图可能仍显示正在接收。 | 按尝试切换标注并收起旧窗口，历史尝试可核对实际已封口文件。 |
| AGY-10 | 接受 | 设置说明和 §13 应与实现一致。用户要求沿用版本。 | 更新 logTailBytes 说明，将 E1 补遗归到设计 §13，保留当前版本。 |

| CLAUDE-02 | 接受 | 缺少描述记录不能推断核心版本。 | 缺记录统一使用中性提示；运行的超时等已知事实另外显示。 |
| CLAUDE-03 | 接受 | 核心状态机与两端契约需要进入自动检查。 | 与 GLM-02、AGY-06 一并落实，断言不改变内存结果。 |
