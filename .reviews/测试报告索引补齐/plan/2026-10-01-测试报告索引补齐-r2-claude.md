### 3.0 IO 接口（CODEX-02）

判定函数只经三个回调接触文件系统：

- `read(rel)`：读文件文本，读不到返回 `null`；
- `list(rel)`：列目录的**直接**子项名（不递归），读不到返回 `null`；
- `kind(rel)`：`'file' | 'dir' | 'other' | null`（`null` = 不存在）。

工作树实现：`kind` 用 `statSync`（**跟随软链**），常规文件 ⇒ `file`、目录 ⇒ `dir`、其余 ⇒ `other`。
git 实现（只在证据脚本里，§5.1）：所有调用前缀 `-c core.quotePath=false`；`list` / `kind` 由**不带 `-r`** 的逐层 `ls-tree <提交>:<目录>` 求得，模式 `100644` / `100755` ⇒ `file`、`040000` ⇒ `dir`、其余（`120000` 软链、`160000` 子模块）⇒ `other`。两种实现给出同形语义。

### 3.1 论域

- **索引 README**：`doc/` 下每个一级子目录的 `README.md`，其中恰有一行 `## 当前已归档文件`（整行、去首尾空白后相等；围栏代码块内的行不算）的即入论域。**按规则求，不手抄。**
- **下限清单**：`KNOWN_INDEXED_DIRS` = S5 的六个目录。测试断言论域 ⊇ 下限清单——有人改了某份 README 的节标题、它就从论域里悄悄掉出去，这里先红（与 facade T2「根级门面文件都在论域内」同形）。新增目录带了这一节会自动入论域，不必改清单。
- 节标题出现两次以上 ⇒ `section_ambiguous`，红（哪一节算索引说不清）。

### 3.2 节与条目的解析

- **节范围**：从节标题下一行到下一个一级或二级标题（`# ` / `## `）之前；`###` 小节属于本节（02_design 靠它分组）。围栏代码块（```）内的行跳过。
- **条目**：节内**顶格**以 `- [` 起头、紧跟 `](目标)` 的列表项；目标即该项的**第一条**链接。其余链接（条目描述里的、非列表行里的）是**行内链接**。
- 不起头于链接的列表项（05_testing 的 `` `evidence/` ``）不是条目，不参与对账。
- 命名规范表、测试分层要求等其它节的文字不在判据内（S9 的示例文件名因此不报）。
- **目标解析**：去掉 `#…` 片段 → **去掉尾部斜杠**（CODEX-02；05_testing 的行内链接都是 `./evidence/名称/` 形态）→ `decodeURIComponent`（失败则用原文）→ 相对 README 所在目录求仓库相对路径（POSIX 语义）；带协议（`http(s):`、`mailto:` 等）与纯 `#锚点` 的不解析。

### 3.3 判据（每条失败都点名 README 与文件）

### 3.4 顺序判据的口径（GLM-01 钉死报告粒度）

- **分组**：按 `###` 小节分组（无 `###` 的节整节一组）；只看**本目录条目**（跨目录条目不参与排序）。
- **组内规则**，按条目出现顺序逐条走，维护「本组已见的最后一条含日期条目」：
  - 本条**不含日期**（`CASE_` / `PLAN_` / `BENCHMARK_` / `ADR_` / `LLD_` 等）而本组此前已出现含日期条目 ⇒ 报一条 `order`（「非报告文件要排在报告之前」；落实「非报告文件放在最前」）；
  - 本条**含日期**，且 (日期, 完整文件名码点序) **不严格大于**本组上一条含日期条目 ⇒ 报一条 `order`，文案点名本条与上一条。
  - 日期取文件名里第一个 `YYYY-MM-DD`。
- **粒度**：每条条目至多报一条 `order`，只与「上一条含日期条目」比，不数全部 i<j 违序对。起点 05_testing 因此恰报 4 条（S4），§5.1 的期望即按此口径；一条长期垫底的条目（如 :54）只报一次，修好一处即少一条，读数可对账。
- **为什么按小节分组、不做整节全序**：02_design 按类别组织（S8），现在整节的日期子序列碰巧升序，但以后在「唯一实现依据」小节加一份新日期的设计文档，会与下方「受控增量规范」小节 09-13 那份形成整节逆序——那不是错。分组后五份非 05_testing 的 README 现状全部满足（已核：每个小节要么只有无日期条目，要么只有一条含日期条目）。
- **无日期条目之间不排序**（02_design 的 `ADR_002` 在 `ADR_001` 前是新者在上的有意安排，不在判据内）。
