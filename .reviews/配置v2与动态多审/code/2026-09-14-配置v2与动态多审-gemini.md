**问题**：decideMode 判定的基准集合未严格收敛于 selectedSides，若 results 传入未入选侧的结果会污染判定。

**依据**：src/trivium/runner.ts:257-267 中 ran = Object.keys(results)，okSides = ran.filter(...)，failedSides 包含 ran 中非 ok 的所有侧。若 selected 仅为 ['gemini']，但外部在 results 中传入了带有失败状态的 'glm'，failedSides 会将未入选的 glm 计入并判定为 single/degraded: true 甚至在 strict 策略下触发 abort；若传入成功的 glm，okSides 也会包含未入选侧。判定基准应严格闭合在 selectedSides 集合内。

**建议**：以 selectedSides 为全集论域计算判定：okSides 与 failedSides 均应限定在 selectedSides 之内（例如 okSides = selectedSides.filter(...)，missingSides = selectedSides.filter(c => !(c in results))，failedSides = selectedSides.filter(c => !okSides.includes(c))），确保纯函数的输入契约完备防御冗余键。
