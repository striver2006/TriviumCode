### AGY-01 · 次要（minor）

| 项 | 内容 |
| :--- | :--- |
| 位置 | `scripts/agent-access-admission.mjs:43-45` |
| 类别 | correctness ｜ 层次 code |

**问题**：当 routeName 为 'native' 时，profile 为 null，静态版本证据读取路径拼接为 'static-null-version-1'，导致查找失败抛错，且探针指纹校验使用了错误的 'profile:null' 键名

**依据**：scripts/agent-access-admission.mjs 第 39 行设置 profile = routeName === 'native' ? null : ...；第 43 行 staticFile 构造为 path.join(root, 'routes', `static-${profile}-version-1`, 'result.json')，当 profile 为 null 时解析为 static-null-version-1，而 static 探测生成的目录为 static-native-version-1，致使第 45 行抛出 '先补当前profile版本证据'；同时第 115 行读取 ctx.config.probe.cli.claude?.routes?.[`profile:${profile}`] 同样在 profile 为 null 时拼出非法的 'profile:null'（规范键名见 claude-route.ts 的 claudeRouteKey，为 'native'）。

**建议**：在静态版本文件路径拼接与探针检索时，对 profile === null 显式回退为 'native'，或者统一调用 src/trivium/adapters/claude-route.ts 导出的 claudeRouteKey(profile) 函数构造键名与目录名。

### AGY-02 · 次要（minor）

| 项 | 内容 |
| :--- | :--- |
| 位置 | `scripts/agent-access-budget.cjs:84-88` |
| 类别 | contract ｜ 层次 code |
| 置信度 | high |

**问题**：vendorOf 及 cp.spawn 钩子未兼容 child_process.spawn(command, options) 的参数重载形态，当调用方省略 args 传递 options 对象时会抛出 TypeError

**依据**：Node.js child_process.spawn 规范允许省略 args 数组而直接将 options 作为第二个参数传入。在 scripts/agent-access-budget.cjs 第 84 行 vendorOf(bin, args = []) 中直接执行 args.find(...)，当 args 为 options 对象时抛出 'args.find is not a function'；在 scripts/agent-access-budget-preload.cjs 第 21-27 行 cp.spawn = function (bin, args = [], options = {}) 中，当 args 为对象时，args.indexOf 与 args.includes 同样会报错。

**建议**：在 cp.spawn 拦截器与 vendorOf 函数入口处规范化参数：判断如果 Array.isArray(args) 为 false，则将 options 修正为 args，并将 args 置为空数组 []，确保参数形态符合预期且不破坏全局 spawn 的标准行为。
